# 1. 概要

## 1.1 背景と課題

時計アプリにアラームがずらっと並んでいる状態は、おかしい。これが出発点である。

- 「家を出る」「早起き」のように、やりたいことは1つなのに、アラームを何本も作って並べている。
- 「出発の30分前」のように逆算で決まる時刻を、毎回頭で計算して入力している。
- 使い終わったアラームが一覧に残り続け、次に使う時に探してオンにし直している。

一方で、1日の予定を毎日きれいに管理できる人は多くない。必要なのは1日の計画ではなく、「今からこれをする」と決めた瞬間に、必要なアラームがすぐ揃うことである。

## 1.2 コンセプト

1つのアクションに必要なアラームを「セット」として保存し、タップ1つで呼び出すiOSアプリ。

「家を出る」をタップして出発時刻を入れれば、30分前のアラームが入る。「早起き」をタップすれば、起床と二度寝対策が入る。使い終わったら消えるので、一覧に並び続けることはない。

- メインコピー：アラーム、もう並べない。
- サブコピー：何時に出る？ それだけ。／逆算は、アプリがやる。

セットとは、1つのアクション（家を出る、早起き、昼寝など）に必要なアラームの組み合わせである。1日の予定をまとめて管理するものではない。

## 1.3 プロダクト原則

機能の追加や仕様で迷った時は、次の5つで判断する。

1. **1アクション＝1セット**：単位は「やること」。1日の計画は扱わない。
2. **すぐ呼び出せる**：開始までの操作は「セットを選ぶ→時刻を確認→開始」の3手以内。
3. **入力は基準1つ**：出発時刻や起床時刻を1つ入れれば、他は逆算で決まる。前回の値を初期値にする。
4. **鳴るのは最小限**：1つの用事に原則1回。複数回鳴らすのは二度寝対策だけ。
5. **確実に鳴り、必ず止まる**：大事なアラームは消音中でも鳴る。ただし鳴り続けには上限を設ける。終わったセットは一覧から消える。

## 1.4 やらないこと

- 1日の予定をまとめて管理する機能（曜日ごとの自動割当を含む）
- 1つのアクションを細かいステップに分ける機能
- 料理、運動、ポモドーロのような連続・ループ型タイマー
- Android版

# 2. 基盤

## 2.1 アプリケーション基盤

iOS専用、対応はiOS 26以降。鳴動は「強＝AlarmKit」「弱＝ローカル通知」の2系統で実装する。データはローカル保存。

ユースケース、主要フロー、プリセット設計、機能スコープ、未確定事項は方針書（2026-10-08）を正とし、Story に着手するときに必要な部分をこの文書と `docs/screens/` に移す。
