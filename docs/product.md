# 1. 概要

## 1.1 プロダクト概要

本アプリは、「家を出る」「早起き」「昼寝」のような、これからやることを1つ選ぶだけで、必要なアラームがまとめて入る iOS アプリである。

ユーザーはアラームの時刻を1本ずつ作らない。やることを選び、「何時にそれをするか」を答えるだけでよい。「何分前に知らせるか」はセットが覚えている。

流れは次の3手である。

1. **やることを選ぶ**: ホームに並んだセット（例: 「家を出る」）をタップする
2. **時刻を答える**: 「何時に出ますか？」に答える。前回の時刻が最初から入っている。「昼寝」のように今から始めるものは、この手順がない
3. **開始する**: 必要なアラームが入る。例: 8:00 に出るなら 7:30 に鳴る

鳴り終わったセットはホームから消える。アラームが一覧に並び続けることはない。

## 1.2 プロダクトビジョン

**アラーム、もう並べない。**

- 何時に出る？ それだけ。
- 何分前に鳴らすかは、アプリが覚えている。

## 1.3 対象ユーザー

時計アプリにアラームを何本も並べて、オンとオフを切り替えながら使っている人。

特に、以下のような使い方をしている人を想定する。

- 「家を出る」のように1つの用事のために、アラームを何本も作っている
- 「出発の30分前」のような時刻を、毎回自分で計算して入力している
- 使い終わったアラームが残り続け、次に使うときに探してオンにし直している

## 1.4 プロダクト原則

機能の追加や仕様で迷った時は、次の5つで判断する。

1. **時刻ではなく、やることをセットする**: ユーザーが選ぶのは「家を出る」「早起き」のような用事であり、アラームの時刻ではない。1つの用事に必要なアラームは、1つのセットにまとめる。
2. **すぐ呼び出せる**: 開始までの操作は「やることを選ぶ → 時刻を答える → 開始」の3手以内にする。
3. **聞くのは「何時に」だけ**: 「何時に出ますか？」「何時に起きますか？」のように、ユーザーが答えるのはその用事をする時刻1つだけ。「何分前に知らせるか」はセットに保存しておき、毎回は聞かない。
4. **知らせ方はセットごとに選べる**: 本番のアラームに加えて、少し前のリマインドや二度寝対策を、セットごとにオプションとして付けられる。用事によって必要な知らせ方は違うので、ここは選べることを大事にする。
5. **確実に鳴り、必ず止まる**: 大事なアラームは消音モードや集中モード中でも鳴る。鳴り続ける時間には上限を設ける。終わったセットはホームから消える。

# 2. 基盤

## 2.1 アプリケーション基盤

- iOS 専用。対応は iOS 26 以降
- 鳴らし方は2種類。消音中でも鳴る「アラーム」（AlarmKit）と、通常の「通知」（ローカル通知）
- データは端末内に保存する

## 2.2 基本概念

### セット

1つの用事（家を出る、早起き、昼寝など）に必要なアラームをまとめたもの。名前、アイコン、時刻の決め方、アラーム（それぞれ「何分前か」と「アラームか通知か」）、スヌーズ、前回の時刻を持つ。

最初から使えるテンプレートを同梱し、ユーザーは選ぶだけで使える。

### 時刻の決め方

| 決め方            | ユーザーが答えること           | 例                                                         |
| ----------------- | ------------------------------ | ---------------------------------------------------------- |
| 何時にするか      | 「何時に〜しますか？」         | 家を出る: 8:00 に出る → 7:30 に鳴る                        |
| 今から            | なし（開始した瞬間から数える） | 昼寝: 開始から 20 分後に鳴る                               |
| 1つの時刻から複数 | 「何時に起きますか？」         | 寝る時間: 起床時刻から就寝の声かけと起床のアラームが決まる |

### 動いているセット

開始したセット。ホームの上部に「家を出る　出発 8:00 ／ 7:30 に鳴ります」のように表示し、取り消せる。すべてのアラームが鳴り終わると消える。

## 2.3 やらないこと

- 1日の予定をまとめて管理する機能（曜日ごとの自動割当を含む）
- 1つの用事を細かいステップに分ける機能
- 料理、運動、ポモドーロのように、ステップが続いたり繰り返したりするタイマー
- Android 版
