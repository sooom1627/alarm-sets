# 作る

## 目的 / 対応 Story

- 行動を作るシート。種類を先に選ばせず、1画面で入れる（[product.md](../product.md) 1.3）
- 開いて閉じる: S-001 #3。名前、分数、いつ鳴らすか、保存: S-002 #6。リマインド: S-003 #7。使うときの流れの3行: S-004 #11

## 入りと出

- ルート: `/create`（`src/app/create.tsx`）。`presentation: "formSheet"`
- 入り: 行動の一覧のヘッダー右の作るボタン。行動の一覧が 0 件のときのカードの作るボタン
- 出: 保存すると閉じ、行動の一覧に戻る（作った行動が最後に並ぶ）。保存せずにシートを下げても閉じ、何も保存しない

## レイアウト

```
┌──────────────────────────────┐
│            ───               │  ← グラバー
│ 新しい行動                     │  ← ネイティブのヘッダー
│                                │
│ 名前                           │
│ ┌────────────────────────────┐ │
│ │ 例: 家を出る                │ │  ← プレースホルダー
│ └────────────────────────────┘ │
│ 時間                           │
│ ┌────────────────────────────┐ │
│ │           29 分             │ │
│ │         [ 30 分 ]           │ │  ← ホイール
│ │           31 分             │ │
│ └────────────────────────────┘ │
│ [5][10][15][20][30][45][60]    │  ← チップ（選んだ分数が sun）
│                                │
│ いつ鳴らしますか？              │
│ (●) 押してから 30 分後に鳴らす  │
│     例: 昼寝して 30 分後に起こす │
│ ( ) 目標時間の 30 分前に鳴らす  │
│     例: 家を出る 30 分前に知らせる│
│                                │
│ リマインド              [ ○ ]  │  ← 目標時間のときだけ
│ 鳴る時間の        [−] 10 分前 [+]│  ← オンのときだけ
│                                │
│ 使うときの流れ                  │

│                                │
```

## 収まり

- 6.1 インチ以上の iPhone では、リマインドがオフならスクロールせずに保存まで収まる。小さい画面や、中身が増えたときはスクロールする

## 出すデータ

- ヘッダーのタイトル: 新しい行動（英語: New action）
- 名前: 前後の空白を除いて 1〜16 文字。初期値は空。プレースホルダーは「例: 家を出る」
- 時間（分）: 1〜240 を 1 分ずつ並べたホイールで選ぶ。初期値は 30。部品は `@expo/ui/swift-ui` の Picker（`pickerStyle("wheel")`）で、高さは 3 行分（120pt）に詰める。ホイールの下のチップは 5 / 10 / 15 / 20 / 30 / 45 / 60 で、押すとホイールがその分数になる。今の分数と同じチップが選ばれた見た目になる
- いつ鳴らしますか？: 2 つから 1 つを選ぶ。初期値は「押してから」。文と例の分数は、入れた分数がそのまま入る
  - 押してから ○ 分後に鳴らす（例: 昼寝して ○ 分後に起こす）
  - 目標時間の ○ 分前に鳴らす（例: 家を出る ○ 分前に知らせる）
- リマインド: 「目標時間の ○ 分前」を選んだときだけ出る。スイッチの初期値はオフ。オンにすると分数が出る（5〜60 を 5 ずつ、初期値は 10）。本番の分数との大小は制限しない。「押してから」に切り替えるとリマインドは出なくなり、保存しない
- 使うときの流れ: 選んだ方の流れを3行で出す。名前、分数、リマインドは入れた値を使い、名前が空なら「この行動」とする
  - 押してから: 一覧で「名前」を押す / 確認なしで、その場でスタートする / ○ 分後に鳴る
  - 目標時間の: 一覧で「名前」を押す / 目標時間を入れる（前回の時間が入っています） / 目標時間の ○ 分前に鳴る（リマインドがオンなら「。その ○ 分前にリマインド」を続ける）
- 保存: 名前が空のあいだは押せない色にする。エラー文は出さない

## 空 / 読込 / エラー

- 空: 名前が空のときは保存を押せない（上）。分数はホイールとチップで選ぶので、空や 0 にはならない
- 読込: 読み込むものは無い
- エラー: 保存に失敗したら、シートを閉じずに入力を残す
