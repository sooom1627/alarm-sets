# 行動の一覧

## 目的 / 対応 Story

- 作った行動を並べ、押して呼び出す起点にする
- 枠（タブ、ヘッダー、ボタン）: S-001 #3。行動のタイルと 0 件の表示、地のグラデーション: S-002 #6。押してスタートする: E-003

## 入りと出

- ルート: `/`（`src/app/(tabs)/(home)/index.tsx`）。起動すると最初に出るタブ
- タブ名: ホーム（英語: Home）
- ヘッダー右の作るボタン → 作るのシート（`/create`）
- ヘッダー右の設定ボタン → 設定のシート（`/settings`）
- タブバー → 動いているもの（[running.md](./running.md)）

## レイアウト

```
┌──────────────────────────────┐
│ ホーム                 [+] [⚙] │  ← ネイティブのヘッダー（大きいタイトル）
│ ┌─────────────┐┌─────────────┐ │
│ │▶ 押してから ││◷ 目標時間の │ │  ← タイル（2 列）
│ │昼寝         ││家を出る     │ │
│ │20 分後      ││30 分前      │ │
│ └─────────────┘└─────────────┘ │
│ ┌─────────────┐                │
│ │▶ 押してから │                │
│ │お茶を淹れる │                │
│ │4 分後       │                │
│ └─────────────┘                │
├──────────────────────────────┤
│   [ホーム]   [実行中]   │  ← NativeTabs
└──────────────────────────────┘
```

- 作るボタンはヘッダー右に置く（NativeTabs には浮いた + を足せないため）。アイコンは SF Symbols の `plus`
- 設定ボタンもヘッダー右。アイコンは SF Symbols の `gearshape`
- 地は空色から淡い黄色へのグラデーション（`grad-1`〜`grad-4`、上から下）

## 出すデータ

- ヘッダーのタイトル: ホーム（英語: Home）
- 行動のタイル: 作った順に 2 列で並べる（新しいものが最後）。1 枚に出すのは次の 3 つ
  - ラベル: 「押してから」（アイコン `play`）か「目標時間の」（アイコン `clock`）
  - 名前
  - 分数と「分後」か「分前」。分数は Geist Mono
- タイルの読み上げ: 「昼寝、押してから20分後に鳴る」「家を出る、目標時間の30分前に鳴る」

## 空 / 読込 / エラー

- 空（0 件）: 「最初の行動を作りましょう」と「「昼寝」「家を出る」のように、タイマーを鳴らしたい行動を作っておくと、次からはここで押すだけで鳴らせます。」のカードと、作るのシートを開く「行動を作る」ボタン
- 読込: 端末内の SQLite から読むので、読込中は何も出さない
- エラー: 読み出しに失敗したら、0 件のカードの代わりに失敗したことと「もう一度」ボタンを出す
