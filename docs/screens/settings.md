# 設定

## 目的 / 対応 Story

- アプリの設定を変えるシート
- 開いて閉じる: S-001 #3。表示言語を選ぶ: S-011 #29

## 入りと出

- ルート: `/settings`（`src/app/settings.tsx`）。`presentation: "formSheet"`
- 入り: 両方のタブのヘッダー右の設定ボタン
- 出: シートを下げると閉じ、開く前のタブに戻る

## レイアウト

```
┌──────────────────────────────┐
│            ───               │  ← グラバー
│ 設定                           │
│                                │
│ 言語                           │
│ ┌───────────┬───────────┐      │
│ │  English  │  日本語   │      │  ← どちらか1つを選ぶ
│ └───────────┴───────────┘      │
│                                │
└──────────────────────────────┘
```

## 出すデータ

- 表示言語: English / 日本語。今の言語が選ばれている
- 言語の表示名はそれぞれの言語で書き、翻訳しない

## 空 / 読込 / エラー

- 言語は同期で読めるので、読込の状態は持たない
- 保存した値が不正なら、保存していないものとして端末の言語から決める（#26）
