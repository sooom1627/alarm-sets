# 目標時間を聞く

## 目的 / 対応 Story

- 「目標時間の ○ 分前」の行動を押したときに1画面だけ出し、目標時間を入れてスタートする（[product.md](../product.md) 1.4）
- S-006 #15（入れると鳴る時刻が出る: #16、前回の時間: #17、スタート: #18）

## 入りと出

- ルート: `/target-time`（`src/app/target-time.tsx`）。`presentation: "formSheet"`。パラメータは行動の id（`actionId`）
- 入り: 行動の一覧で「目標時間の ○ 分前」のタイルを押す
- 出: 「○:○ に鳴らしてスタート」を押すとスタートして閉じ、行動の一覧に戻る。押した直後は一覧と同じトースト（[action-list.md](./action-list.md) の「押したとき」）。シートを下げると閉じ、何もスタートしない
- 行動が見つからない、またはパラメータが不正なら閉じる

## レイアウト

```
┌──────────────────────────────┐
│            ───               │  ← グラバー
│ 家を出る                       │  ← ネイティブのヘッダー（行動の名前）
│                                │
│ 目標時間は？                   │
│ 「家を出る」の時間を入れると、  │
│ その 30 分前に鳴ります          │
│ ┌────────────────────────────┐ │
│ │         7    55             │ │
│ │       [ 8 :  00 ]           │ │  ← 時と分のホイール（DatePicker）
│ │         9    05             │ │
│ └────────────────────────────┘ │
│                                │
│ 鳴る時刻                       │
│ ● 7:20  リマインド              │  ← リマインドがあるときだけ
│ ● 7:30  アラーム                │  ← 時刻は red
│ ○ 8:00  目標時間（鳴らない）     │
│                                │
│ ┌────────────────────────────┐ │
│ │    7:30 に鳴らしてスタート   │ │  ← 主ボタン。シートの下に固定
│ └────────────────────────────┘ │
└──────────────────────────────┘
```

## 出すデータ

- ヘッダーのタイトル: 行動の名前
- 問い: 「目標時間は？」（英語: Target time?）。下に「『{名前}』の時間を入れると、その {分数} 分前に鳴ります」
- 目標時間: `@expo/ui/swift-ui` の DatePicker（`displayedComponents: ["hourAndMinute"]`、`datePickerStyle("wheel")`）。時と分だけを選ぶ
  - 初期値: その行動で前回スタートしたときの目標時間（時と分）
  - 前回が無いとき: 今から分数後を 5 分単位に切り上げた時刻（14:03 に 30 分前の行動なら 14:35。アラームは 14:05）
- 鳴る時刻: 目標時間を変えるとその場で変わる。上から早い順に並べる
  - リマインド: 目標時間 −（分数＋リマインドの分数）。リマインドがある行動だけ
  - アラーム: 目標時間 − 分数。時刻は red
  - 目標時間: 白丸と「目標時間（鳴らない）」。目標時間には鳴らさない
- 時刻の決まり
  - アラームの時刻が今以前になるなら、目標時間を翌日に回す。時刻には「明日」を付ける（「明日 7:30」）
  - リマインドの時刻だけが今以前なら、リマインドは鳴らさない。リマインドの行に「もう過ぎているので鳴りません」と出し、打ち消し線を引く
  - 時刻は端末の 12 / 24 時間制に従う。24 時間制では「7:30」（時の先頭に 0 を付けない）
- スタートのボタン: 「{アラームの時刻} に鳴らしてスタート」（明日なら「明日 7:30 に鳴らしてスタート」）。押すと、アラームとリマインドの時刻でスタートを保存し、その目標時間を前回の目標時間として残す

## 空 / 読込 / エラー

- 空: 無い（目標時間はいつも入っている）
- 読込: 端末内の SQLite から読むので、読込中は何も出さない
- エラー: スタートの保存に失敗したら、シートを閉じずにエラーのトースト「スタートできませんでした」を出す
